## 2. Inteligencia Artificial (IA)

### Definición

La inteligencia artificial es una tecnología que permite a los sistemas informáticos realizar tareas que normalmente requieren inteligencia humana, como comprender textos, reconocer patrones o generar contenido.

### Características principales

- Puede analizar grandes cantidades de información.
- Permite automatizar tareas repetitivas.
- Puede generar textos, imágenes y respuestas mediante modelos de IA generativa.

### Aplicación en Microsoft

Microsoft utiliza la inteligencia artificial en Microsoft 365 Copilot, una herramienta que ayuda a los usuarios a redactar documentos en Word, resumir correos en Outlook y trabajar con información en otras aplicaciones de Microsoft 365.

También ofrece servicios de inteligencia artificial mediante Microsoft Azure para que otras empresas puedan desarrollar sus propias soluciones.

### Mejora en IT y OT

En el ámbito IT, la inteligencia artificial ayuda a automatizar procesos informáticos, analizar información y mejorar la productividad de los trabajadores.

En el ámbito OT, los servicios de IA de Azure pueden integrarse en soluciones industriales para analizar datos procedentes de máquinas o sensores, facilitando tareas como la detección de anomalías. Esto es una posibilidad de aplicación, no una función de Microsoft 365 Copilot.

## 3. Cloud Computing (Computación en la nube)

### Definición

El Cloud Computing es una tecnología que permite utilizar servidores, almacenamiento, bases de datos y aplicaciones a través de Internet, sin necesidad de tener toda la infraestructura informática en las instalaciones de una empresa.

### Características principales

- Permite acceder a los servicios y datos desde diferentes lugares mediante Internet.
- Ofrece escalabilidad, es decir, aumentar o reducir los recursos según las necesidades.
- Reduce la necesidad de comprar y mantener servidores físicos propios.

### Aplicación en Microsoft

Microsoft ofrece servicios de Cloud Computing mediante Microsoft Azure, una plataforma que permite a otras empresas alojar aplicaciones, almacenar información y utilizar servidores virtuales.

Por ejemplo, Azure Virtual Machines permite crear servidores virtuales en la nube, mientras que Azure Storage ofrece servicios de almacenamiento de datos.

### Mejora en IT y OT

En el ámbito IT, Azure facilita la gestión de servidores, aplicaciones y datos, permitiendo adaptar los recursos informáticos a las necesidades de cada empresa.

En el ámbito OT, Azure puede recibir información procedente de dispositivos y sensores industriales mediante soluciones de Internet de las Cosas (IoT). Esto permite conectar sistemas físicos con aplicaciones informáticas para supervisar procesos y analizar datos.
