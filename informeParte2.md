## 4. Resumen ejecutivo

Microsoft es una empresa multinacional del sector TIC dedicada al desarrollo de software, servicios en la nube y soluciones tecnológicas para particulares y empresas.

En este informe analizamos cuatro tecnologías habilitadoras digitales (THD) presentes en sus productos y servicios: Inteligencia Artificial, Cloud Computing, Big Data y Ciberseguridad.

Estas tecnologías permiten automatizar tareas, almacenar y analizar grandes cantidades de información y proteger los sistemas informáticos. También facilitan la integración entre IT (tecnologías de la información) y OT (tecnologías de operación), especialmente mediante soluciones que conectan dispositivos industriales con plataformas en la nube.

## 5. Big Data

### Definición

El Big Data es el conjunto de tecnologías que permiten almacenar, procesar y analizar grandes cantidades de datos, que pueden proceder de distintas fuentes y generarse a gran velocidad.

### Características principales

- Permite procesar grandes volúmenes de información.
- Puede analizar datos de diferentes formatos, como textos, registros y datos de sensores.
- Facilita el análisis de información para tomar decisiones.

### Aplicación en Microsoft

Microsoft ofrece Microsoft Fabric, una plataforma que permite a las empresas recopilar, almacenar, transformar y analizar datos desde un mismo entorno.

Una de sus herramientas es OneLake, que permite centralizar los datos de una organización para utilizarlos en diferentes procesos de análisis.

Por ejemplo, una empresa puede utilizar Microsoft Fabric para analizar información de ventas, detectar tendencias y crear informes que ayuden a tomar decisiones.

### Mejora en IT y OT

En el ámbito IT, Big Data facilita el análisis de información empresarial, reduce la dispersión de los datos y permite obtener informes útiles para la toma de decisiones.

En el ámbito OT, Microsoft Fabric puede combinarse con soluciones de Azure IoT para analizar información procedente de sensores y equipos industriales.

Por ejemplo, una fábrica podría enviar datos sobre el funcionamiento de sus máquinas y analizarlos para detectar anomalías o anticipar posibles fallos.

## 6. Ciberseguridad

### Definición

La ciberseguridad es el conjunto de tecnologías y medidas utilizadas para proteger sistemas informáticos, redes, dispositivos y datos frente a ataques y accesos no autorizados.

### Características principales

- Protege los sistemas frente a amenazas como virus, malware y ataques informáticos.
- Permite detectar actividades sospechosas y responder ante posibles incidentes.
- Ayuda a proteger la información y controlar los accesos a los sistemas.

### Aplicación en Microsoft

Microsoft desarrolla soluciones de ciberseguridad como Microsoft Defender XDR, una plataforma que permite detectar, investigar y responder a amenazas informáticas.

Esta herramienta reúne información de diferentes servicios de seguridad de Microsoft para identificar ataques que puedan afectar a dispositivos, correos electrónicos o identidades de usuarios.

Por ejemplo, Microsoft Defender XDR puede detectar un archivo malicioso y, dependiendo de su configuración, recomendar o realizar acciones para detener la amenaza, como poner el archivo en cuarentena o aislar un dispositivo.

### Mejora en IT y OT

En el ámbito IT, Microsoft Defender XDR facilita la detección de amenazas, la protección de dispositivos y la respuesta ante incidentes de seguridad.

En el ámbito OT, proteger los sistemas informáticos conectados con instalaciones industriales ayuda a reducir los riesgos de accesos no autorizados y ataques que puedan afectar a la producción.

La protección específica de máquinas y redes industriales requiere soluciones de seguridad OT adicionales. Por tanto, Microsoft Defender XDR no debe considerarse por sí solo una protección completa para todos los equipos industriales.

## 7. Conclusiones

Después de analizar las cuatro tecnologías habilitadoras digitales de Microsoft, consideramos que el Cloud Computing es una de las más importantes para su modelo de negocio.

La razón principal es que Microsoft Azure permite ofrecer servicios de almacenamiento, servidores, bases de datos e inteligencia artificial a empresas de todo el mundo.

Además, la nube facilita la integración de otras tecnologías, como Big Data, Inteligencia Artificial e Internet de las Cosas.

Por ejemplo, una empresa industrial puede conectar sensores a servicios de Azure, almacenar sus datos y analizarlos para mejorar sus procesos.

Aunque las cuatro tecnologías son importantes, consideramos que el Cloud Computing es especialmente determinante porque proporciona una infraestructura que permite desarrollar y utilizar muchas de las demás soluciones digitales de Microsoft.
